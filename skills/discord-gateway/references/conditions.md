# 条件式

JS風の小さな式を字句解析・構文解析し、登録・更新・起動時に評価器を作る。
JavaScriptそのものを実行しない。

## 参照値

- event_type: Discord GatewayのDispatch名。
- data: 元のDiscordイベント本体。
- context: EC2が補った情報。context.channel.parent_idなど。
- 配列メソッドの引数: a => a.filenameのように参照する。

存在しないプロパティはnullとして扱う。
==と===はどちらも型を変換しない比較とする。文字列の"8"と数値8は一致しない。
null・undefinedはnullリテラルとして使える。

## 文法

文字列・数値・真偽値・null、配列リテラル、プロパティ参照、添字参照、括弧を使える。
&&・||・!、==・!=・===・!==・<・<=・>・>=を使える。
代入、文、ループ、任意の関数呼び出しは使えない。

## メソッド

| メソッド | 内容 |
| --- | --- |
| some(a => 条件) | 配列内に一致する要素がある |
| every(a => 条件) | 配列内のすべての要素が一致する |
| includes(値) | 文字列の部分一致、または配列内の値の一致 |
| startsWith(文字列) | 前方一致 |
| endsWith(文字列) | 後方一致 |
| toLowerCase() / toUpperCase() | 大文字小文字の変換 |
| matches("正規表現") | Goの正規表現で一致を調べる。パターンは文字列リテラルのみ |

空配列のsomeはfalse、everyはtrue。
対象が配列でないsome/everyはfalse。
添付に関する条件を参照した場合、成立した式の対象添付をルートのattachmentsへ追加する。
同じ添付は1回だけ含め、元の順序を保つ。

## 同じ添付への条件

PDFかつサイズ上限を満たす添付を選ぶ場合は、条件を同じsomeの中へ置く。

```js
data.attachments.some(a =>
  a.content_type == "application/pdf" && a.size < 1048576
)
```

別々のsomeをANDで組み合わせると、PDFが存在することと小さい添付が存在することを、それぞれ別の要素でも満たせる。
その場合は、それぞれの成立条件の対象添付をまとめる。

## 制限

条件式は16 KiB、構文木は2048ノード、括弧等のネストは64まで。
1回の評価は200000ステップを上限とする。
上限超過はエラーとして記録し、無制限にCPUやメモリを消費しないようにする。
